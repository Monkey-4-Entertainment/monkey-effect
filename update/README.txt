Monkeyeffect 1.4.1.1 · Windows — แก้เลขรุ่นเก่าและการแจ้งอัปเดตซ้ำ

- แก้แถบด้านข้างและหน้าอัปเดตที่ยังแสดง 1.4.0 แม้ติดตั้ง 1.4.1 สำเร็จแล้ว
- ทุกจุดอ่านเลขรุ่นจากตัวโปรแกรมที่กำลังทำงาน ไฟล์ข้อมูลเว็บเก่าจะไม่ทำให้เลขรุ่นย้อนกลับหรือแจ้งติดตั้งซ้ำ
- ปรับไฟล์ข้อมูลรุ่นในชุดอัปเดตและ Setup ให้ตรงกับโปรแกรม และเพิ่มการตรวจความสอดคล้องก่อนเผยแพร่
- รวมตัวแก้ผู้พิทักษ์ 3 อันดับทั้ง 5 ธีม และ Overlay/OBS แนวตั้ง 9:16 จาก 1.4.1 ครบ

ติดตั้งทับโฟลเดอร์ Monkeyeffect เดิมได้ โดยเก็บการตั้งค่า พรีเซ็ต และไฟล์ผู้ใช้ไว้
เครื่องที่ใช้ 1.4.1 สามารถอัปเดตเป็นแพตช์นี้ได้แม้หน้าจอยังแสดง 1.4.0
สำหรับเครื่องใหม่ให้ใช้ Setup ส่วน update.zip ใช้กับโปรแกรมที่ติดตั้งแล้ว
