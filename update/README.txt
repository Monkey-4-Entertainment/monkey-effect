Monkeyeffect 1.4.3 — พรีเซ็ตของขวัญและรีเซ็ต Widget

- ช่องของขวัญในพรีเซ็ตแสดงรูป ชื่อ และราคาเหรียญ พร้อมค้นหาและเลือกเปลี่ยนได้ในแถว
- ปรับรายการเลือกของขวัญเป็นธีมกรม–ม่วง อ่านง่าย พร้อมคลังรูปกลาง 1,837 รายการ ใช้งานรูปที่เก็บในโปรแกรมได้โดยไม่ต้องเชื่อมต่อเว็บ
- เพิ่มปุ่มทดลองเข้าเกมในทุกแถวเหตุการณ์ ทดสอบแอคชันของแถวนั้นโดยไม่ต้องบันทึกฉบับร่าง
- รีเซ็ตยอด ของขวัญ เลเวล และอันดับผู้พิทักษ์/สุลต่านแยกตาม Widget โดยเก็บหน้าตา ขนาด และตำแหน่งเดิม
- รวมการแก้ไขระบบอัปเดตจาก 1.4.2.1 และเก็บพรีเซ็ตกับข้อมูลผู้ใช้เดิม

ราคาของขวัญอ้างอิงคลังรูปที่มากับรุ่นนี้ อาจแตกต่างตามภูมิภาคหรือการเปลี่ยนแปลงของ TikTok
บันทึกค่าที่แก้ก่อนอัปเดต โปรแกรมจะปิดและเปิดใหม่ระหว่างติดตั้ง
หากอัปเดตในโปรแกรมไม่สำเร็จ ให้ใช้ Setup ติดตั้งทับโฟลเดอร์เดิม
