Monkeyeffect 1.4.1 · Windows

- แก้ 3 อันดับผู้พิทักษ์ไม่ขึ้นใน Widget ทั้งแมว มังกร จิ้งจอก โหลแก้ว และเรือ พร้อมช่องรอผู้สนับสนุนสำหรับจัดตำแหน่งก่อนเริ่มไลฟ์
- อัปเดตอันดับทันทีเมื่อได้รับของขวัญ และป้องกันการนับซ้ำจากคิวส่งเข้าเกม
- แก้ขนาดและตำแหน่ง Overlay กับลิงก์ OBS ให้ใช้ฉากเดียวกัน พร้อมบันทึกขนาดหน้าต่าง
- คงหน้าต่างแนวตั้ง 9:16 และแสดงเต็มพื้นที่ OBS 720×1280 หรือ 1080×1920 โดยไม่ย่อภาพซ้ำ
- แถบจัดตำแหน่งไม่ดันภาพให้เล็กลง และการเปิด–ปิดโหมดจัดตำแหน่งไม่เปลี่ยนสัดส่วน

อัปเดตผ่านหน้าอัปเดตใน Monkeyeffect ได้ตามปกติ ตัว Setup เป็นชุดติดตั้งครบสำหรับเครื่องใหม่หรือติดตั้งทับโฟลเดอร์เดิม โดยเก็บการตั้งค่าและพรีเซ็ตไว้
